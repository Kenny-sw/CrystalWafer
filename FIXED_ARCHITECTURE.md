## 🔄 Рабочий Процесс

### 1️⃣ Начальное Состояние

```
Верхняя панель показывает:
├─ "Готов к работе"
└─ [Начать партию] (видна)

Пользователь может:
├─ Выбрать тип изделия из loadDataComboBox
├─ Ввести SizeX, SizeY, WaferDiameter
└─ Нажать "Создать карту" (кнопка Create)
```

**Что происходит при нажатии "Создать карту":**
1. Читаются значения из полей `SizeX`, `SizeY`, `WaferDiameter`
2. Создается `WaferTemplate` из этих параметров
3. Автоматически генерируется имя партии (Партия_001, Партия_002...)
4. Открывается конструктор с предзаполненными значениями

### 2️⃣ Редактирование Черновика

```
Появляется большая панель конструктора:
┌────────────────────────────────────┐
│ Конструктор карты (черновик)       │
│ Редактирование партии: Партия_001  │
├────────────────────────────────────┤
│ Диаметр D:    [200] мм             │
│ Ширина W:     [10.0] мм  ← из SizeX
│ Высота H:     [10.0] мм  ← из SizeY
│ Дорожка:      [0.0] мм              │
│ Смещение X:   [0.0] мм              │
│ Смещение Y:   [0.0] мм              │
│ ☐ Отразить X  ☐ Отразить Y         │
│                                    │
│ Точная подстройка:                 │
│ [←][→][↑][↓] [X/2][Y/2] [W↔H]     │
│                                    │
│ [Сохранить карту] [Отмена]         │
└────────────────────────────────────┘
```

**Возможности:**
- ✅ Все изменения отображаются в реальном времени на визуализаторе
- ✅ Кнопки точной подстройки используют шаг из карты
- ✅ "Сохранить" → переход в MapReady
- ✅ "Отмена" → возврат в Initial, данные не сохраняются

### 3️⃣ Карта Готова (MapReady)

```
Верхняя панель показывает:
├─ "✅ Партия: Партия_001 | Обработано: 0"
├─ [Редактировать карту] (оранжевая)
└─ [Новая пластина] (бирюзовая)

Параметры пластины остаются видимыми!
Можно посмотреть/изменить настройки.
```

**Действия:**
- "Редактировать карту" → возврат в режим редактирования
- "Новая пластина" → начало обработки пластины

### 4️⃣ Обработка Пластины

```
Верхняя панель показывает:
├─ "🔄 Обработка: Партия_001_Пластина_001"
├─ [Завершить пластину] (зеленая)
└─ [Завершить партию] (фиолетовая)
```

**Действия:**
- "Завершить пластину" → счетчик +1, возврат в MapReady
- "Завершить партию" → архивация, возврат в Initial
