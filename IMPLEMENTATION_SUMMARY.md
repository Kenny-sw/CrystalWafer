## 🎯 Рабочий процесс

### Начальное состояние
```
[Шаблон: ▼]  [Создать карту]
```

### После создания карты
```
Партия: Партия_001 | Пластин: 0
[Редактировать карту]  [Новая пластина]
```

### Обработка пластины
```
Обработка: Партия_001_Пластина_001
[Завершить пластину]  [Архивировать партию]
```

## 🚀 Быстрый старт

1. **Создание новой карты:**
   - Нажмите "Создать карту"
   - Введите название и выберите шаблон
   - Настройте параметры
   - Нажмите "Сохранить"

2. **Работа с пластинами:**
   - Нажмите "Новая пластина"
   - Выполните обработку
   - Нажмите "Завершить пластину"

3. **Завершение партии:**
   - Нажмите "Архивировать партию"
   - Шаблон сохраняется для повторного использования

## ⚠️ Важные замечания

- Старые данные из `crystal_data.txt` автоматически мигрируют в шаблоны
- Все шаблоны сохраняются в `%AppData%`
- Каждая пластина в партии получает уникальный номер
- Редактирование через черновики предотвращает случайные изменения
