## ❗ КРИТИЧЕСКОЕ ИЗМЕНЕНИЕ

### Упрощена система фиксации

**Было (НЕПРАВИЛЬНО):**
- Пин 6 (ENABLE) - включение/отключение драйверов
- Пин 8 (LOCK) - управление соленоидом фиксации через реле
- Команда Lock (0x05) - активация реле
- Команда Unlock (0x06) - деактивация реле

**Стало (ПРАВИЛЬНО):**
- Пин 6 (ENABLE/LOCK) - **ДВОЙНАЯ функция:**
  - **HIGH** = моторы включены + стол зафиксирован + движение разрешено
  - **LOW** = моторы выключены + стол расфиксирован + движение запрещено
- ~~Пин 8 (LOCK)~~ - **УДАЛЁН**
- Команда Lock (0x05) - установить пин 6 в HIGH
- Команда Unlock (0x06) - установить пин 6 в LOW

## 🔧 ИЗМЕНЕНИЯ В КОДЕ

### Arduino (StepByStepOOP1.4.ino)

1. **Удалён пин 8:**
```cpp
// УДАЛЕНО:
// const uint8_t PIN_LOCK = 8;

// ОСТАЛОСЬ:
const uint8_t PIN_ENA = 6;  // ENABLE + LOCK
```

2. **Упрощена функция setLock():**
```cpp
void setLock(bool locked) {
  digitalWrite(PIN_ENA, locked ? HIGH : LOW);
  g_isLocked = locked;
  
  Serial.print(F("EV L:"));
  Serial.println(locked ? 1 : 0);
  Serial.println(F("OK"));
}
```

3. **Добавлена защита движения:**
```cpp
void doMoveCmd(byte cmd, uint32_t steps) {
  // Проверка: можно двигаться только если стол зафиксирован
  if (!g_isLocked) {
    Serial.println(F("ERR:UNLOCKED"));
    return;
  }
  
  // ... выполнение движения
}
```

4. **Инициализация:**
```cpp
void setup() {
  pinMode(PIN_ENA, OUTPUT);
  digitalWrite(PIN_ENA, LOW);  // Старт: расфиксирован
  g_isLocked = false;
}
```

### C# (без изменений)

Код C# уже правильно работает с протоколом:
- `Protocol.Commands.Lock` (0x05)
- `Protocol.Commands.Unlock` (0x06)
- Обработка `ERR:UNLOCKED` через `Protocol.Responses.IsError()`
- Обработка событий `EV L:1` / `EV L:0`

## 📡 ПРОТОКОЛ

### Команды (без изменений)

| Команда | Код | Описание |
|---------|-----|----------|
| Lock | 0x05 | PIN_ENA = HIGH (моторы вкл, стол зафиксирован) |
| Unlock | 0x06 | PIN_ENA = LOW (моторы выкл, стол расфиксирован) |

### Ответы

| Ответ | Значение |
|-------|----------|
| `OK` | Команда выполнена |
| `ERR:UNLOCKED` | **НОВОЕ:** Попытка движения без фиксации |
| `EV L:1` | Событие: стол зафиксирован |
| `EV L:0` | Событие: стол расфиксирован |

## 🔌 СХЕМА ПОДКЛЮЧЕНИЯ

### Было (НЕПРАВИЛЬНО):
```
Arduino PIN 6 ──► Драйверы (ENABLE)
Arduino PIN 8 ──► Реле 5V ──► Соленоид 24V
```

### Стало (ПРАВИЛЬНО):
```
Arduino PIN 6 ──► Драйверы (ENABLE)
                   ↓
        HIGH = моторы держат позицию (зафиксированы)
        LOW  = моторы свободны (расфиксированы)
```

**Физическая реализация фиксации:**
- **Электромагнитная:** Моторы держат момент при ENABLE=HIGH
- **Механическая (опционально):** Соленоид/реле можно подключить параллельно к ENABLE, если требуется дополнительная фиксация

## ✅ ПРОВЕРКА РАБОТОСПОСОБНОСТИ

### Тест 1: Фиксация работает
```
1. Нажать "🔓 Фиксация" в программе
2. Результат:
   - Arduino отправляет: "EV L:1" + "OK"
   - Моторы "схватывают" позицию (сопротивление при попытке повернуть вал)
   - Кнопка меняется на "🔒 Сброс" (красная)
   - Статус: "Фиксация: ВКЛ"
```

### Тест 2: Движение возможно только при фиксации
```
1. Убедиться, что стол НЕ зафиксирован (кнопка "🔓 Фиксация" зелёная)
2. Попробовать нажать стрелку → (вправо)
3. Результат:
   - Arduino отправляет: "ERR:UNLOCKED"
   - Движения НЕТ
   
4. Нажать "🔓 Фиксация"
5. Повторить стрелку → (вправо)
6. Результат:
   - Arduino отправляет: "OK"
   - Стол движется вправо
```

### Тест 3: Сброс работает
```
1. Нажать "🔒 Сброс" (если зафиксирован)
2. Результат:
   - Arduino отправляет: "EV L:0" + "OK"
   - Моторы отпускают (вал свободно крутится)
   - Кнопка меняется на "🔓 Фиксация" (зелёная)
   - Статус: "Фиксация: ВЫКЛ"
```

## 📋 МИГРАЦИЯ (если уже была собрана старая версия)

1. **Отключить пин 8** (если был подключен соленоид/реле)

3. **Проверить Serial Monitor:** должно быть "READY" при старте

## 🎯 ПРЕИМУЩЕСТВА НОВОГО ПОДХОДА

1. **Упрощение:** Один пин вместо двух
2. **Надёжность:** ENABLE автоматически фиксирует моторы
3. **Безопасность:** Движение невозможно без явной фиксации
4. **Экономия:** Не требуется реле и соленоид (если достаточно момента моторов)
5. **Совместимость:** Протокол не изменился, код C# работает без правок
