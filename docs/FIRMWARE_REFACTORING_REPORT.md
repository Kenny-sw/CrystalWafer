### 3. Исправлены проблемы и неточности

#### ❌ ПРОБЛЕМА #1: Отсутствие `pumpEdgeEvent()` в OptocouplerWiring

**Было (в DirectWiring):**
```cpp
// ❌ Убрано из циклов движения (правильно)
for (uint32_t i = 1; i <= accel; ++i) {
  pulseStep();
  delayMicroseconds(...);
  // pumpEdgeEvent(); ← Закомментировано
}
```

**Было (в OptocouplerWiring):**
```cpp
// ✅ Оставлено в циклах (но это медленно)
for (uint32_t i = 1; i <= accel; ++i) {
  pulseStep();
  delayMicroseconds(...);
  pumpEdgeEvent();  // ← Тормозит на 100-500мкс!
}
```

**Решение:** В новой OptocouplerWiring оставил `pumpEdgeEvent()` В ЦИКЛАХ, так как:
1. В некоторых приложениях важно отслеживать датчик во время движения
2. Если нужна максимальная скорость - пользователь может закомментировать

**Компромисс:** Добавил комментарий с предупреждением о влиянии на производительность.
