# 📷 Система управления USB-камерой и компьютерное зрение

## 🎯 Обзор реализации

Система управления USB-камерой полностью интегрирована в приложение CrystalTable и предоставляет:

### ✅ Реализованные компоненты

#### 1. **CameraController** (`Camera/CameraController.cs`)
- ✅ Инициализация и управление USB-камерой
- ✅ Захват видеопотока в реальном времени
- ✅ Настройка параметров изображения (яркость, контраст, экспозиция и т.д.)
- ✅ Сохранение снимков
- ✅ Заморозка кадра (freeze frame)
- ✅ Поддержка нескольких камер

#### 2. **CameraSettingsForm** (`Camera/CameraSettingsForm.cs`)
Полнофункциональное окно настроек с параметрами:
- **Базовые параметры изображения:**
  - Яркость (0-100)
  - Контраст (0-100)
  - Насыщенность (0-100)
  - Резкость (0-10)
  - Усиление/Gain (0-100)

- **Экспозиция:**
  - Автоматическая/ручная экспозиция
  - Значение экспозиции (1-1000 мс)

- **Баланс белого:**
  - Автоматический/ручной баланс белого
  - Температура цвета (2000-10000 K)

- **Разрешение и FPS:**
  - 640x480, 800x600, 1280x720, 1920x1080
  - 15, 30, 60 FPS

#### 3. **Form1.Camera.cs** - интеграция в главную форму
- ✅ Кнопки в тулбаре:
  - 📷 "Камера" - включение/выключение камеры
  - ⚙️ "Настройки" - открытие окна настроек
  - 📸 "Снимок" - сохранение текущего кадра
  - ❄️ "Стоп-кадр" - заморозка изображения
  
- ✅ Превью камеры в правом верхнем углу
- ✅ Автоматический выбор камеры (если подключено несколько)
- ✅ Отображение статуса камеры в status bar

#### 4. **ComputerVisionController** (`ComputerVision/ComputerVisionController.cs`)
Набор алгоритмов компьютерного зрения:

##### Реализованные функции:
- ✅ **DetectFiducials()** - поиск фидуциальных меток на пластине
  - Используется для автоматической калибровки координат
  - Определение центра пластины
  - Обнаружение круглых и квадратных меток

- ✅ **DetectDefects()** - поиск дефектов на кристаллах
  - Обнаружение темных пятен, царапин
  - Классификация по степени серьезности (Minor/Moderate/Critical)
  - Морфологические операции для фильтрации шума

- ✅ **MeasureCrystal()** - измерение геометрических параметров
  - Определение размеров кристалла (ширина, высота)
  - Вычисление площади
  - Определение центра кристалла

- ✅ **AlignToMap()** - совмещение изображения с картой
  - Автоматическое сопоставление меток
  - Вычисление параметров трансформации
  - Синхронизация координат камеры и карты

- ✅ **ClassifyCrystal()** - автоматическая классификация
  - Определение качества кристалла (годен/брак)
  - Подсчет количества дефектов
  - Вычисление общего показателя качества (0-100%)

## 📦 Требуемые NuGet пакеты

### ⚠️ ВАЖНО: Необходимо установить следующие пакеты

Проект использует **AForge.NET Framework** для работы с камерой и компьютерного зрения.

### Способ 1: Через Visual Studio (рекомендуется)

1. Откройте **Solution Explorer**
2. Правой кнопкой мыши на проект **CrystalTable**
3. Выберите **Manage NuGet Packages...**
4. Во вкладке **Browse** найдите и установите:

```
AForge                           v2.2.5
AForge.Video                     v2.2.5
AForge.Video.DirectShow          v2.2.5
AForge.Imaging                   v2.2.5
AForge.Math                      v2.2.5
```

### Способ 2: Через Package Manager Console

Откройте **Tools → NuGet Package Manager → Package Manager Console** и выполните:

```powershell
Install-Package AForge -Version 2.2.5
Install-Package AForge.Video -Version 2.2.5
Install-Package AForge.Video.DirectShow -Version 2.2.5
Install-Package AForge.Imaging -Version 2.2.5
Install-Package AForge.Math -Version 2.2.5
```

### Способ 3: Ручное редактирование packages.config

Добавьте в файл `WindowsFormsApp1\packages.config`:

```xml
<package id="AForge" version="2.2.5" targetFramework="net472" />
<package id="AForge.Video" version="2.2.5" targetFramework="net472" />
<package id="AForge.Video.DirectShow" version="2.2.5" targetFramework="net472" />
<package id="AForge.Imaging" version="2.2.5" targetFramework="net472" />
<package id="AForge.Math" version="2.2.5" targetFramework="net472" />
```

Затем выполните: **Tools → NuGet Package Manager → Restore NuGet Packages**

## 🚀 Использование

### Включение камеры

1. Подключите USB-камеру к компьютеру
2. Запустите приложение
3. Нажмите кнопку **"📷 Камера"** в тулбаре
4. Превью появится в правом верхнем углу

### Настройка изображения

1. Нажмите **"⚙️ Настройки"** в тулбаре
2. Отрегулируйте параметры изображения
3. Нажмите **"Применить"**

### Сохранение снимка

1. При работающей камере нажмите **"📸 Снимок"**
2. Выберите место сохранения
3. Файл будет сохранен в формате PNG или JPEG

### Использование компьютерного зрения

```csharp
// Создание контроллера CV
var cvController = new ComputerVisionController();

// Получение кадра с камеры
var frame = cameraController.GetCurrentFrame();

// Поиск меток
var fiducials = cvController.DetectFiducials(frame);

// Поиск дефектов
var defects = cvController.DetectDefects(frame);

// Классификация
var classification = cvController.ClassifyCrystal(frame);
if (classification.IsGood)
{
    // Кристалл годен
}
```

## ⚙️ Системные требования

- **ОС:** Windows 7/8/10/11
- **.NET Framework:** 4.7.2 или выше
- **USB-камера:** совместимая с DirectShow
- **Разрешение:** рекомендуется 1280x720 или выше
- **Процессор:** Intel Core i5 или аналог (для обработки видео)

## 📝 Примечания

1. **Производительность:** Обработка CV выполняется в отдельном потоке для предотвращения зависания UI
2. **Совместимость:** Поддерживаются все камеры с драйверами DirectShow
3. **Калибровка:** Для точных измерений требуется калибровка по эталонному объекту известного размера
4. **Освещение:** Качество распознавания зависит от освещения - рекомендуется равномерное белое освещение

## 🐛 Устранение неполадок

### Камера не обнаружена
- Убедитесь, что камера подключена
- Проверьте драйверы устройства в Диспетчере устройств
- Попробуйте другой USB-порт

### Плохое качество изображения
- Отрегулируйте фокус камеры
- Улучшите освещение
- Настройте параметры в окне настроек

### Низкая производительность
- Уменьшите разрешение камеры
- Снизьте частоту кадров
- Отключите ресурсоемкие фильтры
