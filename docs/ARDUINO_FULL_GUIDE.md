## ⚡ БЫСТРЫЙ СТАРТ

### Подключение Arduino

```
1. Загрузить скетч: Arduino\StepByStepOOP1.4.ino
2. Подключить драйверы шаговых двигателей (A4988/DRV8825)
3. Подключить моторы X и Y
4. Подключить датчик края к пину 7
5. Проверить питание: 5V для Arduino, 12-24V для драйверов
6. В программе: нажать "Connect" → выбрать COM-порт
```

### Первый запуск

```
1. Нажать "🔓 Фиксация" → моторы включаются (стол зафиксирован)
2. Проверить движение: стрелки ←→↑↓
3. Нажать "🔒 Сброс" → моторы отключаются (стол расфиксирован)
```

## 🔌 РАСПИНОВКА

| **Пин** | **Функция** | **Тип** | **Уровень** | **Описание** |
|---------|------------|---------|-------------|--------------|
| **2** | DIR_X | Выход | HIGH/LOW | Направление оси X (LOW=влево, HIGH=вправо) |
| **3** | DIR_Y | Выход | HIGH/LOW | Направление оси Y (LOW=вниз, HIGH=вверх) |
| **4** | STEP_Y | Выход | Импульсы 4мкс | Шаговые импульсы для оси Y |
| **5** | STEP_X | Выход | Импульсы 4мкс | Шаговые импульсы для оси X |
| **6** | **ENABLE/LOCK** | **Выход** | **HIGH/LOW** | **HIGH=моторы вкл/стол зафиксирован, LOW=моторы выкл/стол расфиксирован** |
| **7** | EDGE_SENSOR | Вход | Прерывание | Датчик края пластины (оптический/индуктивный) |

### ⚠️ КРИТИЧЕСКАЯ ОСОБЕННОСТЬ ПИН 6

**Пин 6 выполняет ДВОЙНУЮ функцию:**

1. **ENABLE для драйверов** → Включение/отключение питания моторов
2. **LOCK для системы** → Фиксация/сброс стола

**Логика работы:**

```
PIN_ENA = HIGH (команда 0x05 Lock)
  ├─► Драйверы получают питание
  ├─► Моторы держат момент (зафиксированы)
  ├─► ЛШД может двигаться по командам
  └─► Статус: "Стол ЗАФИКСИРОВАН"

PIN_ENA = LOW (команда 0x06 Unlock)
  ├─► Драйверы обесточены
  ├─► Моторы свободны (без момента)
  ├─► ЛШД НЕЛЬЗЯ двигать (ERR:UNLOCKED)
  └─► Статус: "Стол РАСФИКСИРОВАН"
```

## ⚙️ СИСТЕМА STEP/DIRECTION

### Принцип работы

**Step/Direction** - стандартный интерфейс для драйверов шаговых двигателей.

#### 1. Направление (DIR)

Устанавливается **ПЕРЕД** началом движения и **удерживается** всё время движения.

| **Команда** | **Код** | **Ось** | **DIR пин** | **Уровень** |
|------------|---------|---------|-------------|-------------|
| MoveLeft | 0x01 | X | 2 | LOW |
| MoveRight | 0x02 | X | 2 | HIGH |
| MoveUp | 0x03 | Y | 3 | HIGH |
| MoveDown | 0x04 | Y | 3 | LOW |

```cpp
// Пример: движение вправо
digitalWrite(PIN_DIR_X, HIGH);  // Установить направление
delay(1);                        // Небольшая задержка для стабилизации
// ... затем генерация импульсов
```

#### 2. Шаговые импульсы (STEP)

Каждый импульс = 1 шаг мотора (с учетом микрошага драйвера).

**Параметры импульса:**
- **Длительность HIGH:** 4 мкс
- **Пауза между импульсами:** 200-800 мкс (динамическая)
- **Форма:** Прямоугольная

```cpp
// Генерация одного импульса
digitalWrite(PIN_STEP_X, HIGH);
delayMicroseconds(4);
digitalWrite(PIN_STEP_X, LOW);
delayMicroseconds(200);  // Пауза зависит от профиля скорости
```

#### 3. Профиль скорости (Трапеция)

Движение разделено на 3 фазы для плавности:

```
Задержка (мкс)
  800 ├─┐
      │  ╲                                        ╱
      │   ╲______________________________________╱
  200 │   
      └────────────────────────────────────────────► Шаги
      0%    30%         70%              100%
      
      ◄───► Разгон    ◄──────► Крейсер   ◄───► Торможение
       30%              40%                30%
```

**Формула интерполации:**
```cpp
delay(i) = maxDelay - (maxDelay - minDelay) × (i / accelSteps)
```

**Настройки по умолчанию:**
```cpp
uint16_t minDelay = 200;   // мкс, максимальная скорость (крейсер)
uint16_t maxDelay = 800;   // мкс, минимальная скорость (старт/финиш)
byte accelPercent  = 30;   // 30% расстояния на разгон
byte cruisePercent = 40;   // 40% на постоянную скорость
byte decelPercent  = 30;   // 30% на торможение
```

### Пример: Движение вправо 5000 мкм

```
1. PC отправляет:      [0x02][0x88 0x13 0x00 0x00][XOR]
                        └─► MoveRight, 5000 микрошагов
                        
2. Arduino проверяет:  g_isLocked == true? → Да, продолжаем
                                           → Нет, "ERR:UNLOCKED"
                        
3. Устанавливает DIR:  PIN_DIR_X = HIGH (вправо)

4. Генерирует импульсы с трапецией:
   
   Шаги 0-1500:    800→200 мкс (разгон)
   Шаги 1500-3500: 200 мкс (крейсер)
   Шаги 3500-5000: 200→800 мкс (торможение)
   
5. Arduino отправляет: "OK\r\n"
```

## 🔒 СИСТЕМА ФИКСАЦИИ

### Назначение

**Фиксация** = включение моторов + возможность движения  
**Сброс** = отключение моторов + блокировка движения

### Логика работы

```
┌──────────────────────────────────────────────────────────────────────┐
│                    КОМАНДА LOCK (0x05)                               │
└──────────────────────────────────────────────────────────────────────┘

PC → Arduino: [0x05]
                │
                ↓
         ┌──────────────┐
         │ if cmdLock:  │
         │  setLock(1)  │
         └──────────────┘
                │
                ↓
         ┌──────────────────────────┐
         │ digitalWrite(PIN_6, HIGH)│ ──► Моторы ВКЛЮЧЕНЫ
         │ g_isLocked = true        │ ──► Флаг фиксации
         └──────────────────────────┘
                │
                ↓
         ┌──────────────┐
         │ Serial print │
         │ "EV L:1"     │ ──► Arduino → PC: "EV L:1\r\n"
         │ "OK"         │ ──► Arduino → PC: "OK\r\n"
         └──────────────┘

Результат:
  • Драйверы получают ENABLE
  • Моторы держат позицию (момент удержания)
  • Команды движения разрешены
  • Кнопка в ПО: "🔒 Сброс" (красная)


┌──────────────────────────────────────────────────────────────────────┐
│                   КОМАНДА UNLOCK (0x06)                              │
└──────────────────────────────────────────────────────────────────────┘

PC → Arduino: [0x06]
                │
                ↓
         ┌──────────────┐
         │ if cmdUnlock:│
         │  setLock(0)  │
         └──────────────┘
                │
                ↓
         ┌──────────────────────────┐
         │ digitalWrite(PIN_6, LOW) │ ──► Моторы ВЫКЛЮЧЕНЫ
         │ g_isLocked = false       │ ──► Снять флаг
         └──────────────────────────┘
                │
                ↓
         ┌──────────────┐
         │ Serial print │
         │ "EV L:0"     │ ──► Arduino → PC: "EV L:0\r\n"
         │ "OK"         │ ──► Arduino → PC: "OK\r\n"
         └──────────────┘

Результат:
  • Драйверы обесточены
  • Моторы свободны (можно крутить вручную)
  • Команды движения заблокированы → "ERR:UNLOCKED"
  • Кнопка в ПО: "🔓 Фиксация" (зелёная)
```

### Защита от движения без фиксации

```cpp
void doMoveCmd(byte cmd, uint32_t steps) {
  // Проверка: можно двигаться только если стол зафиксирован
  if (!g_isLocked) {
    Serial.println(F("ERR:UNLOCKED"));
    return;
  }
  
  // ... выполнение движения
}
```

**Зачем это нужно:**
- Предотвращение случайного движения при настройке
- Безопасность оператора
- Ручное позиционирование (при LOW моторы свободны)

## 🔍 ДАТЧИК КРАЯ

### Назначение

Определяет наличие пластины под ЛШД в режиме реального времени.

### Реализация

#### 1. Аппаратное прерывание

```cpp
attachInterrupt(digitalPinToInterrupt(PIN_EDGE), ISR_edgeChange, CHANGE);
```

**CHANGE** = Реагирует на оба фронта (↑ и ↓)

**Преимущества:**
- ⚡ Мгновенная реакция (микросекунды)
- 🔄 Не блокирует выполнение команд
- 📡 События даже во время движения моторов

#### 2. Антидребезг (300 мкс)

```cpp
void ISR_edgeChange() {
  uint32_t now = micros();
  bool s = readEdgePin();
  
  // Фильтр дребезга
  if (now - g_edgeLastUs >= EDGE_DEBOUNCE_US) {  // 300 мкс
    g_edgeRaw = s;
    g_edgeLastUs = now;
    g_edgeChanged = true;  // Установить флаг события
  }
}
```

**Алгоритм:**
```
Сигнал датчика → Проверка времени → (>300мкс?) → Принять → Флаг события
                                   ↓ (<300мкс?)
                               Игнорировать (дребезг)
```

#### 3. Доставка событий

```cpp
void pumpEdgeEvent() {
  if (g_edgeChanged) {
    noInterrupts();
    bool s = g_edgeRaw;
    g_edgeChanged = false;
    interrupts();
    
    Serial.print(F("EV S:"));
    Serial.println(s ? 1 : 0);
  }
}
```

**Вызов в критических местах:**
```cpp
void loop() {
  pumpEdgeEvent();  // Постоянная проверка в простое
}

void Axis::moveProfile() {
  for (каждый шаг) {
    pulseStep();
    delayMicroseconds(delay);
    pumpEdgeEvent();  // Проверка во время движения
  }
}
```

#### 4. Логика датчика

```cpp
const bool EDGE_ACTIVE_HIGH = true;
```

- `true` → HIGH = пластина обнаружена (PNP транзистор, отраженный свет)
- `false` → LOW = пластина обнаружена (NPN транзистор, прерванный луч)

### Схема подключения (оптический датчик)

```
       +5V
        │
        ├──[220Ω]──[LED]──┐
        │                 │
        └──[10kΩ]─────┐   │ (просвет между LED и фототранзистором)
                      │   │
Arduino Pin 7 ────────┤   │
                      │   │
                  [Phototrans-
                   sistor]
                      │   │
                      └───┴── GND

Принцип:
  • Нет пластины → свет проходит → транзистор открыт → LOW
  • Есть пластина → свет перекрыт → транзистор закрыт → HIGH (подтяжка)
```

### События

```
EV S:1  → Пластина обнаружена (датчик сработал)
EV S:0  → Пластина покинула зону (датчик отпущен)
```

### Опрос состояния

Команда `0x0B` (SensorQuery) → мгновенный ответ без события:
```
PC → Arduino: [0x0B]
Arduino → PC: "S:1\r\n"  или  "S:0\r\n"
```

## 📡 ПРОТОКОЛ СВЯЗИ

### Формат пакета

```
┌────────┬──────────────────────────┬──────────┐
│ Команда│ Данные (uint32 LE)       │ Checksum │
│ 1 байт │ 4 байта (младший первым) │ 1 байт   │
└────────┴──────────────────────────┴──────────┘

Пример: MoveRight 5000 мкм
  [0x02][0x88 0x13 0x00 0x00][0x9B]
    │     └─ 5000 = 0x1388   └─ XOR всех 5 байтов
    └─ MoveRight
```

### Контрольная сумма (XOR)

```cpp
// Arduino
byte xorChecksum(const byte* data, int len) {
  byte c = 0;
  for (int i = 0; i < len; i++) {
    c ^= data[i];
  }
  return c;
}

// C#
private static byte CalculateChecksum(byte[] buffer, int length) {
    byte checksum = 0;
    for (int i = 0; i < length; i++) {
        checksum ^= buffer[i];
    }
    return checksum;
}
```

### Таблица команд

| **Код** | **Название** | **Данные** | **Ответ** | **Описание** |
|---------|-------------|-----------|----------|--------------|
| `0x01` | MoveLeft | uint32 шаги | OK | Движение влево (требует Lock) |
| `0x02` | MoveRight | uint32 шаги | OK | Движение вправо (требует Lock) |
| `0x03` | MoveUp | uint32 шаги | OK | Движение вверх (требует Lock) |
| `0x04` | MoveDown | uint32 шаги | OK | Движение вниз (требует Lock) |
| `0x05` | **Lock** | - | EV L:1 + OK | **Фиксация (PIN_ENA=HIGH)** |
| `0x06` | **Unlock** | - | EV L:0 + OK | **Сброс (PIN_ENA=LOW)** |
| `0x07` | SetProfile | - | NA | Не реализовано |
| `0x0B` | SensorQuery | - | S:0 / S:1 | Опрос датчика |
| `0x0C` | EdgeTouch | - | NA | Не реализовано |

### Ответы Arduino

| **Ответ** | **Значение** |
|-----------|-------------|
| `OK` | Команда выполнена успешно |
| `ERR:UNLOCKED` | **Попытка движения без фиксации** |
| `ERR:TIMEOUT` | Таймаут приёма данных (>100 мс) |
| `ERR:CS` | Ошибка контрольной суммы XOR |
| `ERR:CMD` | Неизвестная команда |
| `NA` | Команда не реализована |
| `S:0` / `S:1` | Состояние датчика (ответ на 0x0B) |
| `EV S:0` / `EV S:1` | Событие датчика (асинхронное) |
| `EV L:0` / `EV L:1` | Событие фиксации (асинхронное) |
| `READY` | Arduino готов (отправляется при старте) |

│ 3 ──┼──────────→│ DIR      │

### 2. Настройка микрошага (A4988)

```
MS1  MS2  MS3  │ Микрошаг │ Шагов/оборот (для 200-шагового мотора)
─────────────────────────────────────────────────────────────────
LOW  LOW  LOW  │ Full     │ 200
HIGH LOW  LOW  │ 1/2      │ 400
LOW  HIGH LOW  │ 1/4      │ 800
HIGH HIGH LOW  │ 1/8      │ 1600  ← Рекомендуется
HIGH HIGH HIGH │ 1/16     │ 3200

Рекомендация: 1/8 или 1/16 для плавности и точности
```

### 3. Настройка тока драйвера (Vref)

```
Формула для A4988:
  Vref = Imax × 8 × Rcs
  
Где:
  • Imax = номинальный ток мотора (например, 1A)
  • Rcs = 0.05 Ом (для A4988)
  
Пример для мотора 1A:
  Vref = 1.0 × 8 × 0.05 = 0.4V
  
Настройка:
  1. Отключить питание
  2. Подключить мультиметр к Vref (потенциометр на драйвере)
  3. Подать питание
  4. Крутить потенциометр до нужного напряжения
  5. Проверить нагрев драйвера (должен быть радиатор!)
```

### 4. Датчик края (оптический)

```
Схема 1: Отражающий датчик (через барьер)
       
       +5V
        │
        ├──[220Ω]──[LED ●]──┐
        │                   │
        └──[10kΩ]───────┐   │
                        │   │      ╔════╗
Arduino Pin 7 ──────────┤   │      ║    ║ ← Пластина (отражает свет)
                        │   │      ╚════╝
                    [Photo ○]         ↓
                   transistor]      Отражение
                        │   │
                        └───┴── GND

Логика: EDGE_ACTIVE_HIGH = true
  • Нет пластины → нет отражения → LOW
  • Есть пластина → отражение → HIGH


Схема 2: Прерывающий датчик (через просвет)

       +5V                     +5V
        │                       │
        ├──[220Ω]──[LED ●]      └──[10kΩ]───┐
        │              │                     │
        │              └─→ СВЕТ ─→ ╔════╗   │
        │                          ║    ║   │ ← Пластина перекрывает
        └──────────────────────────╚════╝   │
                                             │
Arduino Pin 7 ───────────────────────────────┤
                                             │
                                         [Photo ○]
                                        transistor]
                                             │
                                            GND

Логика: EDGE_ACTIVE_HIGH = true
  • Нет пластины → свет проходит → транзистор открыт → LOW
  • Есть пластина → свет перекрыт → транзистор закрыт → HIGH (подтяжка)


Настройка в коде:
  pinMode(PIN_EDGE, INPUT_PULLUP);  // Внутренняя подтяжка 10кΩ к +5V
  const bool EDGE_ACTIVE_HIGH = true;  // Измените на false для инверсии
```

### 1. Настройка скорости

```cpp
// В начале скетча Arduino:
uint16_t minDelay = 200;   // мкс, максимальная скорость

```

**Слишком медленно?**
```cpp
minDelay = 150;  // или 100 (осторожно!)
maxDelay = 600;
```

### 2. Калибровка профиля

```cpp
byte accelPercent  = 30;  // 30% на разгон
byte cruisePercent = 40;  // 40% на постоянную скорость
byte decelPercent  = 30;  // 30% на торможение
```

**Рывки при старте?** → Увеличить `accelPercent`  
**Рывки при остановке?** → Увеличить `decelPercent`  
**Долгий разгон?** → Уменьшить `accelPercent`, увеличить `cruisePercent`

### 3. Тест датчика

```
1. Загрузить скетч
2. Открыть Serial Monitor (115200 baud)
3. При старте должно быть:
   READY
   EV S:0  (если нет пластины)
   
4. Поднести объект к датчику:
   EV S:1
   
5. Убрать объект:
   EV S:0
```

### 4. Тест моторов

```
1. Подключить COM-порт в программе
2. Нажать "🔓 Фиксация"
   → Статус: "Фиксация: ВКЛ"
   → Моторы должны "захватить" позицию (момент удержания)
   
3. Попробовать покрутить вал мотора вручную
   → Должно быть сопротивление (зафиксирован)
   
4. Нажать стрелку → (вправо)
   → Стол должен двигаться плавно
   
5. Нажать "🔒 Сброс"
   → Моторы отпускают
   → Вал крутится свободно
   
6. Попробовать нажать стрелку →
   → Должна быть ошибка: "ERR:UNLOCKED"
```

## 🐛 ДИАГНОСТИКА ПРОБЛЕМ

### Мотор не двигается

```
┌─► Проверить PIN_ENA (6)
│    └─► Должен быть HIGH (после команды Lock)
│    └─► Мультиметр: ~5V на пине 6
│
├─► Проверить питание драйверов
│    └─► VMOT: 12-24V (отдельный источник!)
│    └─► VDD: 5V от Arduino
│
├─► Проверить импульсы на STEP
│    └─► Осциллограф на пине 5 (STEP_X)
│    └─► Должны быть импульсы 4 мкс при движении
│
├─► Проверить ток драйвера
│    └─► Vref потенциометр (мультиметр)
│    └─► Для мотора 1A: Vref ≈ 0.4V (A4988)
│
└─► Проверить фиксацию
     └─► Статус в программе: "Фиксация: ВКЛ"
     └─► Команда Lock (0x05) должна быть отправлена
```

### ERR:UNLOCKED при попытке движения

```
Причина: Стол не зафиксирован (PIN_ENA = LOW)

Решение:
  1. Нажать кнопку "🔓 Фиксация" в программе
  2. Проверить статус: должно быть "Фиксация: ВКЛ"
  3. Кнопка должна стать красной "🔒 Сброс"
  4. Повторить движение
```

### Датчик не реагирует

```
┌─► Проверить подключение к PIN 7
│    └─► GND и +5V подключены к датчику
│
├─► Проверить EDGE_ACTIVE_HIGH
│    └─► true = HIGH при обнаружении
│    └─► false = LOW при обнаружении
│
├─► Проверить INPUT_PULLUP
│    └─► Должно быть: pinMode(PIN_EDGE, INPUT_PULLUP);
│
├─► Послать команду 0x0B (SensorQuery)
│    └─► Должен ответить: S:0 или S:1
│
└─► Проверить антидребезг
     └─► Если датчик "мигает" → увеличить EDGE_DEBOUNCE_US
     └─► Было: 300 мкс → Попробовать: 500 или 1000 мкс
```

### ERR:CS (ошибка контрольной суммы)

```
Причина: Несовпадение XOR контрольной суммы

Проверить:
  1. C# использует XOR (было исправлено)
     └─► SerialPortController.cs → CalculateChecksum()
     └─► Должно быть: checksum ^= buffer[i]
  
  2. Arduino использует XOR
     └─► Должно быть: c ^= data[i]
  
  3. Формат пакета: 6 байт
     [CMD][D0][D1][D2][D3][XOR]
  
  4. Логи:
     └─► AppLogger.Debug показывает TX/RX пакеты
     └─► Проверить соответствие
```

### Моторы дергаются / пропускают шаги

```
┌─► Увеличить minDelay
│    └─► minDelay = 200 → 300-500 мкс
│    └─► Уменьшает максимальную скорость
│
├─► Проверить микрошаг (MS1/MS2/MS3)
│    └─► Рекомендуется: 1/8 или 1/16
│    └─► Не использовать Full step для точности
│
├─► Проверить ток драйвера (Vref)
│    └─► Слишком малый → мотор слабый
│    └─► Слишком большой → перегрев
│
├─► Добавить конденсаторы на питание
│    └─► 100мкФ на VMOT драйверов
│    └─► Защита от просадок напряжения
│
└─► Проверить механику
     └─► Нет ли заедания?
     └─► Правильная связь мотор-ходовой винт?
```

### COM-порт не подключается

```
┌─► Проверить драйверы USB
│    └─► Диспетчер устройств → Порты (COM)
│    └─► Установить драйвер CH340/CP2102/FTDI
│
├─► Проверить скорость (baud rate)
│    └─► Arduino: Serial.begin(115200);
│    └─► C#: _port.BaudRate = 115200;
│
├─► Перезапустить Arduino
│    └─► Кнопка RESET или отключить/подключить USB
│
└─► Закрыть другие программы
     └─► Arduino IDE Serial Monitor
     └─► Другие терминалы
```

## 🎯 ИТОГОВАЯ СВОДКА

### Ключевые особенности

1. **Пин 6 = ENABLE + LOCK**
   - HIGH → Моторы включены, стол зафиксирован, движение разрешено
   - LOW → Моторы выключены, стол расфиксирован, движение запрещено

2. **Защита от движения без фиксации**
   - Arduino проверяет `g_isLocked` перед движением
   - Ошибка `ERR:UNLOCKED` если попытка движения при LOW

3. **Датчик с прерыванием**
   - Мгновенная реакция (аппаратное прерывание)
   - Антидребезг 300 мкс
   - События во время движения моторов

4. **Профиль скорости (трапеция)**
   - Плавный разгон/торможение
   - Настраиваемые параметры
   - Защита от пропуска шагов

5. **Протокол XOR**
   - Контрольная сумма для защиты от ошибок
   - Синхронизация C# ↔ Arduino
