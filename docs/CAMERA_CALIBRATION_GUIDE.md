# 📐 Калибровка камеры - Руководство пользователя

## 🎯 Что такое калибровка камеры?

**Калибровка камеры** - это процесс определения **масштаба камеры** (сколько миллиметров приходится на один пиксель изображения).

### Зачем это нужно?

| Без калибровки | С калибровкой |
|----------------|---------------|
| Размеры только в пикселях | **Реальные размеры в мм/мкм** |
| Кристалл: 120 × 80 px | Кристалл: **5.82 × 3.88 мм** |
| Дефект: 5 px | Дефект: **0.24 мм (240 мкм)** |
| Смещение: 103 px | Смещение: **5.00 мм** |

---

## 🔧 Процесс калибровки (4 шага)

### ШАГ 1: Запомнить эталонное изображение

1. **Включите камеру** (кнопка "📷 Камера" в тулбаре)
2. **Наведите ЛШД** на область с четкими деталями:
   - Кристаллы с резкими краями
   - Фидуциальные метки
   - Края пластины
3. **Убедитесь в качестве изображения:**
   - ✓ Резкое (в фокусе)
   - ✓ Хорошо освещено
   - ✓ Контрастное
4. Нажмите **"Далее ►"** в мастере калибровки

### ШАГ 2: Настройка и смещение

1. **Выберите ось движения:**
   - ◉ X - горизонтальное смещение (рекомендуется)
   - ○ Y - вертикальное смещение
   
2. **Укажите шаг смещения:**
   - Рекомендуется: **5-10 мм**
   - Минимум: 1 мм
   - Максимум: 50 мм
   
3. **⚠️ ВАЖНО:** Убедитесь, что путь свободен!
   
4. Нажмите **"Захватить и переместить ►"**
   - Система запомнит изображение
   - ЛШД переместится на указанный шаг
   - Может занять 3-5 секунд

### ШАГ 3: Анализ изображения (автоматически)

Система автоматически:
1. Захватывает новый кадр
2. Применяет гистограммную эквализацию для улучшения качества
3. Сопоставляет два изображения
4. Вычисляет смещение в пикселях

**Процесс занимает 2-3 секунды**

Индикаторы качества:
- ✓ Найдено характерных точек: **> 30** (отлично)
- ✓ Точность совпадения: **> 90%** (отлично)

## 🎯 Как запустить калибровку

### Вариант 1: Кнопка в тулбаре

1. Включите камеру: **📷 Камера**
2. Нажмите: **🎯 Калибровка**
3. Следуйте инструкциям мастера

### Вариант 2: Меню (будущее)

```
Меню → Камера → Калибровка...
```

## 📊 Критерии успешной калибровки

| Параметр | Хорошо | Приемлемо | Плохо |
|----------|--------|-----------|-------|
| **Расхождение X/Y** | < 5% | 5-10% | > 10% |
| **Масштаб** | 0.02-0.15 мм/px | 0.01-0.20 | < 0.01 или > 0.5 |
| **Совпадение** | > 95% | 90-95% | < 90% |
| **Характерных точек** | > 40 | 20-40 | < 20 |

### Если калибровка неудачная

**Возможные причины:**
- Плохое освещение → улучшите освещение
- Размытое изображение → настройте фокус
- Слишком малый шаг (< 3 мм) → увеличьте шаг
- Слишком большой шаг (> 20 мм) → уменьшите шаг
- Мало деталей в кадре → наведите на кристаллы

**Решение:** Нажмите **"🔄 Повторить"** и попробуйте снова

## 🔬 Гистограммная эквализация

### Что это?

**Гистограммная эквализация** - автоматическое улучшение контраста изображения.

### Когда помогает?

| Проблема | Решение |
|----------|---------|
| 🌑 Темное изображение | Эквализация осветляет |
| ☀️ Слишком яркое | Эквализация затемняет |
| 🌓 Неравномерное освещение | Выравнивает по всему кадру |
| 💡 Блики от металла | Уменьшает влияние |

### Пример

**ДО эквализации:**
```
Серое изображение, дефекты не видны
Яркость: [███████░░░░░░░░░] 50%
Контраст: [████░░░░░░░░░░░] 25% - ПЛОХО
```

**ПОСЛЕ эквализации:**
```
Контрастное изображение, дефекты четко видны
Яркость: [████████████░░░] 75%
Контраст: [████████████████] 100% - ОТЛИЧНО ✓
```

### Применение в калибровке

Эквализация **автоматически применяется** на шаге 3 для:
1. Улучшения сопоставления изображений
2. Повышения точности измерений
3. Работы при любом освещении

## 💡 Рекомендации

### Подготовка к калибровке

✓ **Включите равномерное освещение**
✓ **Настройте фокус камеры** (в "⚙️ Настройки")
✓ **Убедитесь, что пластина неподвижна**
✓ **Очистите линзу камеры** от пыли
✓ **Наведите на центр пластины** (больше деталей)

### Частота калибровки

| Событие | Действие |
|---------|----------|
| **Первый запуск** | Обязательная калибровка |
| **Изменение расстояния** | Перекалибровка |
| **Изменение разрешения** | Перекалибровка |
| **Изменение объектива** | Перекалибровка |
| **Обычная работа** | 1 раз в неделю (для контроля) |

### Проверка калибровки

1. Измерьте объект известного размера (например, кристалл 5.00 × 5.00 мм)
2. Сравните с эталонным значением
3. Отклонение должно быть < ±0.1 мм

## ❓ Часто задаваемые вопросы

### Q: Почему расхождение X/Y не равно нулю?

**A:** Небольшое расхождение (1-5%) это нормально из-за:
- Микровибраций при движении
- Округления пикселей
- Несовершенства алгоритма

Главное - чтобы расхождение было < 10%

### Q: Можно ли калиброваться по оси Y?

**A:** Да! Выберите **○ Y** на шаге 2. Результат будет тот же.

### Q: Что если шаг 5 мм слишком мал/велик для моей камеры?

**A:** Подберите оптимальный шаг:
- **Широкоугольная камера** (большое поле) → 10-20 мм
- **Узкоугольная камера** (малое поле) → 3-5 мм
- **Микроскоп** → 0.5-2 мм

### Q: Нужно ли перекалибровывать при изменении зума?

**A:** **ДА!** Зум меняет масштаб. Обязательна новая калибровка.

### Q: Калибровка сохраняется между запусками?

**A:** **ДА!** Автоматически сохраняется и загружается при старте программы.
