## ⚠️ КРИТИЧНО: Установка пакетов

**Перед запуском необходимо установить NuGet пакеты!**

Откройте Visual Studio:
1. **Solution Explorer** → правый клик на **CrystalTable**
2. **"Manage NuGet Packages..."**
3. Установите **все 5 пакетов версии 2.2.5**:
   - AForge
   - AForge.Video
   - AForge.Video.DirectShow
   - AForge.Imaging
   - AForge.Math

**Подробная инструкция:** `INSTALL_PACKAGES.md`

## 🎓 Примеры использования

### Базовая работа с камерой
```csharp
var camera = new CameraController();
camera.Initialize(0);
camera.Start();
var frame = camera.GetCurrentFrame();
camera.Stop();
```

### Компьютерное зрение
```csharp
var cvController = new ComputerVisionController();
var classification = cvController.ClassifyCrystal(frame);
if (!classification.IsGood)
{
    // Кристалл дефектный
}
```
