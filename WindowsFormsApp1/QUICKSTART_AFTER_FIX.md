## ❌ Если не работает

### Проблема 1: "Serial command timed out"

**Решение:**
1. Переподключите USB-кабель
2. Откройте Arduino Serial Monitor (115200)
3. Должно появиться "READY"
4. Если нет - перезалейте скетч
5. Переподключитесь в приложении

---

### Проблема 2: "Listener не запущен"

**Решение:**
1. Disconnect в приложении
2. Закройте Arduino Serial Monitor
3. Connect в приложении
4. Проверьте статус

---

### Проблема 3: Arduino не отвечает

**Решение:**
1. Проверьте скорость: 115200 baud
2. Нажмите RESET на Arduino
3. Проверьте Serial Monitor: должно быть "READY"
4. Убедитесь, что загружен правильный скетч

---

## 📋 Быстрая диагностика

| Симптом | Решение |
|---------|---------|
| Timeout | Переподключите USB → Restart приложения |
| IOException | Disconnect → Connect |
| Listener не запущен | Закройте Serial Monitor → Connect |
| Arduino не отвечает | Проверьте скорость 115200 → RESET |
| ERR:CS | Перезалейте скетч (правильный XOR) |
