# 🔧 ИНСТРУКЦИЯ: КАК НАСТРОИТЬ КАМЕРУ

## 📋 ПОШАГОВОЕ РУКОВОДСТВО

### ✅ ШАГ 1: ЗАПУСК КАМЕРЫ

1. Подключите USB-камеру к компьютеру
2. В тулбаре нажмите кнопку **"📷 Камера"**
3. Выберите камеру из списка (если их несколько)
4. Дождитесь сообщения "Камера запущена"

**Индикация работы:**
- ✅ Превью камеры отображается в углу карты
- ✅ Кнопки камеры активны (зеленые)
- ✅ В статус-баре: "Камера: Камера запущена"

---

### ✅ ШАГ 2: ОТКРЫТИЕ НАСТРОЕК

1. Убедитесь что камера **ЗАПУЩЕНА** (см. Шаг 1)
2. Нажмите кнопку **"⚙️ Настройки"** в тулбаре
3. Откроется окно "Настройки камеры"

**Что вы увидите:**
```
┌─────────────────────────────────────┐
│ Статус камеры:                      │
│ 🟢 Камера работает - настройки      │
│    можно применять                  │
└─────────────────────────────────────┘
```

**⚠️ ВАЖНО:** Если статус **🔴 Камера не запущена** - вернитесь к Шагу 1!

---

### ✅ ШАГ 3: ПРОВЕРКА ПОДДЕРЖКИ

**Перед настройкой узнайте возможности камеры!**

1. В окне настроек нажмите **"Проверить поддержку"**
2. Изучите отчет о поддержке

**Пример отчета:**
```
🔍 Поддержка настроек вашей камерой:

✓ = поддерживается    ✗ = не поддерживается

✓ Яркость (Brightness)
✓ Контраст (Contrast)
✓ Насыщенность (Saturation)
✗ Резкость (Sharpness)
✓ Усиление (Gain)
✓ Баланс белого (White Balance)
✓ Экспозиция (Exposure)

📊 Поддерживается: 6 из 7 настроек

ℹ️ Примечание: Неподдерживаемые настройки будут игнорироваться.
Это нормально для большинства веб-камер.
```

**Что делать дальше:**
- ✅ **6-7 из 7** → Отлично! Настраивайте все параметры
- ⚠️ **3-5 из 7** → Хорошо! Используйте поддерживаемые настройки
- ❌ **0-2 из 7** → Плохо! Камера не поддерживает настройки (см. раздел "Проблемы")

---

### ✅ ШАГ 4: НАСТРОЙКА ПАРАМЕТРОВ

#### 📊 Базовые параметры изображения:

**Яркость (0-100):**
- 🔅 Меньше 50 → темнее
- 💡 50 → по умолчанию
- ☀️ Больше 50 → светлее

**Контраст (0-100):**
- 📉 Меньше 50 → мягче
- 📊 50 → по умолчанию
- 📈 Больше 50 → резче

**Насыщенность (0-100):**
- 🌑 0 → черно-белое
- 🎨 50 → нормальные цвета
- 🌈 100 → яркие цвета

**Резкость (0-10):**
- 🌫️ 0 → размытое
- 👁️ 5 → по умолчанию
- 🔍 10 → очень резкое

**Усиление / Gain (0-100):**
- 🌙 0 → без усиления (для яркого света)
- ⚖️ 50 → умеренное
- 💡 100 → максимальное (для темноты, но больше шума)

---

#### ⏱️ Экспозиция:

**Автоматическая экспозиция:**
- ✅ **Включено** (рекомендуется) → камера сама регулирует
- ❌ **Выключено** → ручная настройка

**Ручная экспозиция (1-1000 мс):**
- ⚡ 1-10 мс → быстрый затвор (для движущихся объектов)
- ⏱️ 10-100 мс → нормальная скорость
- 🐌 100-1000 мс → медленный затвор (для темноты)

---

#### 🎨 Баланс белого:

**Автоматический баланс:**
- ✅ **Включено** (рекомендуется) → камера сама корректирует цвета
- ❌ **Выключено** → ручная настройка

**Ручной баланс (2000-10000 K):**
- 🔥 2000-3000 K → теплые тона (лампа накаливания)
- ☀️ 5000-6000 K → нейтральные (дневной свет)
- ❄️ 7000-10000 K → холодные (облачно)

---

### ✅ ШАГ 5: ПРИМЕНЕНИЕ НАСТРОЕК

1. Настройте параметры слайдерами
2. Нажмите кнопку **"Применить"**
3. Дождитесь сообщения о результате

**Успешное применение:**
```
✓ Настройки применены!

Поддерживается: 6 из 7 настроек

Нажмите 'Проверить поддержку' для подробностей.
```

**Если ничего не работает:**
```
⚠️ Камера не поддерживает аппаратные настройки.

Это может быть связано с:
• Дешевой веб-камерой без DirectShow
• Устаревшими драйверами
• Виртуальной камерой (OBS, ManyCam)

Попробуйте:
1. Обновить драйверы камеры
2. Использовать другую USB-камеру
3. Нажать 'Проверить поддержку' для деталей
```

## ❌ ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### Проблема 1: Кнопка "Проверить поддержку" не нажимается

**Причина:** Камера не запущена

**Решение:**
1. Закройте окно настроек
2. Запустите камеру кнопкой **"📷 Камера"**
3. Откройте настройки снова

---

### Проблема 2: Все настройки показывают ✗

**Причина:** Камера не поддерживает DirectShow API

**Возможные причины:**
- Дешевая NoName веб-камера
- Драйвер не реализует IAMVideoProcAmp
- Виртуальная камера (OBS Virtual Camera, ManyCam, Snap Camera)
- Некоторые встроенные камеры ноутбуков

**Решение:**
1. **Обновите драйверы:**
   - Диспетчер устройств → Камеры → Обновить драйвер
   - Скачайте драйверы с сайта производителя

2. **Используйте другую камеру:**
   - Logitech C920/C922/C930e ✅
   - Microsoft LifeCam ✅
   - Razer Kiyo ✅
   - Любая профессиональная USB-камера ✅

3. **Отключите виртуальные камеры:**
   - Закройте OBS / ManyCam
   - Удалите виртуальные камеры из системы

---

### Проблема 3: Настройки применяются, но ничего не меняется

**Причина:** Автоматические режимы переопределяют ручные настройки

**Решение:**
1. Отключите "Автоматическая экспозиция"
2. Отключите "Автоматический баланс белого"
3. Примените настройки снова

---

### Проблема 4: Изображение слишком темное/светлое

**Решение для темного:**
1. Увеличьте "Яркость" до 60-70
2. Увеличьте "Усиление" до 60-80
3. Включите "Автоматическая экспозиция"

**Решение для светлого:**
1. Уменьшите "Яркость" до 30-40
2. Уменьшите "Усиление" до 0-20
3. Установите экспозицию 10-30 мс

---

### Проблема 5: Изображение с шумом

**Причина:** Слишком высокое усиление (Gain)

**Решение:**
1. Уменьшите "Усиление" до 0-30
2. Улучшите освещение
3. Увеличьте экспозицию (50-200 мс)

---

### Проблема 6: Изображение размытое

**Решение:**
1. Увеличьте "Резкость" до 7-10
2. Уменьшите экспозицию (10-50 мс)
3. Проверьте фокусировку камеры
