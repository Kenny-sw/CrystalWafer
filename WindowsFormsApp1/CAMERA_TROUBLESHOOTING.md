# 🚨 БЫСТРОЕ РЕШЕНИЕ ПРОБЛЕМ С КАМЕРОЙ

## ⚡ ЭКСПРЕСС-ДИАГНОСТИКА

### 1️⃣ Камера не запускается
```
❌ Проблема: Кнопка "Камера" не работает

✅ РЕШЕНИЕ:
1. Проверьте USB-подключение
2. Перезапустите программу
3. Выберите другую камеру из списка
4. Перезагрузите компьютр
```

---

### 2️⃣ Кнопка "Проверить поддержку" неактивна
```
❌ Проблема: Не могу проверить возможности

✅ РЕШЕНИЕ:
1. СНАЧАЛА запустите камеру кнопкой "📷"
2. Убедитесь в статусе: 🟢 Камера работает
3. ТОЛЬКО ПОТОМ открывайте настройки
```

---

### 3️⃣ Все настройки показывают ✗
```
❌ Проблема: Камера не поддерживает настройки

✅ РЕШЕНИЕ:
- Дешевая веб-камера? → Купите Logitech C920
- Виртуальная камера? → Отключите OBS/ManyCam
- Старые драйверы? → Обновите в Диспетчере устройств
```

---

### 4️⃣ Настройки не применяются
```
❌ Проблема: Нажал "Применить", ничего не изменилось

✅ РЕШЕНИЕ:
1. Статус должен быть: 🟢 Камера работает
2. Нажмите "Проверить поддержку"
3. Используйте ТОЛЬКО поддерживаемые (✓) настройки
4. Отключите авто-режимы для ручной настройки
```

---

### 5️⃣ Изображение темное
```
❌ Проблема: Ничего не видно

✅ БЫСТРОЕ РЕШЕНИЕ:
Яркость → 70
Усиление → 80
Экспозиция → Авто ✅
```

---

### 6️⃣ Изображение светлое
```
❌ Проблема: Все засвечено

✅ БЫСТРОЕ РЕШЕНИЕ:
Яркость → 30
Усиление → 10
Экспозиция → 20 мс
```

---

### 7️⃣ Много шума
```
❌ Проблема: Зернистое изображение

✅ БЫСТРОЕ РЕШЕНИЕ:
Усиление → 20 (уменьшить!)
+ Улучшите освещение
```

---

### 8️⃣ Размытое изображение
```
❌ Проблема: Нечеткое

✅ БЫСТРОЕ РЕШЕНИЕ:
Резкость → 8
Экспозиция → 30 мс
+ Проверьте фокус камеры
```

---

## 🎯 УНИВЕРСАЛЬНОЕ РЕШЕНИЕ

**Если ничего не помогает:**

### Вариант А: Сброс настроек
```
1. Настройки → Нажать "Сброс"
2. Нажать "Применить"
3. Перезапустить камеру
```

### Вариант Б: Перезапуск камеры
```
1. Кнопка "📷 Камера" → Выключить
2. Подождать 2 секунды
3. Кнопка "📷 Камера" → Включить снова
4. Настройки → "Применить"
```

### Вариант В: Перезапуск программы
```
1. Закрыть CrystalTable
2. Отключить камеру от USB
3. Подключить камеру к USB
4. Запустить CrystalTable
5. Запустить камеру
```

## 📞 ЧТО ДЕЛАТЬ ЕСЛИ НЕ РАБОТАЕТ

### Уровень 1: Самостоятельно (5 минут)
1. Перезапустить камеру
2. Сбросить настройки
3. Проверить USB-кабель

### Уровень 2: Базовая диагностика (15 минут)
1. Проверить поддержку
2. Обновить драйверы
3. Попробовать другую камеру

### Уровень 3: Техподдержка
1. Скриншот "Проверить поддержку"
2. Модель камеры
3. GitHub Issues
