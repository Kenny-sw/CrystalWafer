# Arduino Archive - Устаревшие прошивки

Эта папка содержит устаревшие версии прошивок Arduino, сохранённые для справки.

## Содержимое архива

### StepByStep1.5.ino/
**Оригинальная версия** с профилем 30/40/30.
- Профиль движения: **30% разгон / 40% крейсер / 30% торможение**
- minDelay=200 мкс, maxDelay=800 мкс
- Поддержка датчика края с прерываниями
- Команда SetProfile зарезервирована, но не реализована

### StepByStepOOP1.3.ino
**Промежуточная версия** с ООП архитектурой.

### StepByStepOOP1.4/
**Улучшенная ООП версия** с рефакторингом.

### StepByStepInverS/
**Версия для инверсной логики** (CrystalWaferScannerInverS.ino).
- Для подключения через оптрон
- Инверсная логика сигналов

### _archive_old/
**Старый архив** с ранними версиями.

---

## Замечания

Если требуется работа со старым оборудованием или для отладки, 
эти прошивки можно использовать, но рекомендуется переход на актуальные версии:
- `StepperDriver_DirectWiring.ino`
- `StepperDriver_OptocouplerWiring.ino`

Смотрите главный `README.md` в папке `Arduino/`.
