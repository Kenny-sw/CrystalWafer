# Arduino Firmware - CrystalTable

## Актуальные прошивки

В папке Arduino доступны **2 актуальные прошивки** для разных схем подключения:

### 1. `StepperDriver_DirectWiring/`
**Для прямого подключения** драйвера шагового двигателя к Arduino.
- Логика сигналов: **прямая** (HIGH = активный)
- DIR: HIGH = одно направление, LOW = другое
- STEP: импульс HIGH для шага
- ENA: HIGH = драйвер включен

### 2. `StepperDriver_OptocouplerWiring/`
**Для подключения через оптрон** (гальваническая развязка).
- Логика сигналов: **инверсная** (LOW = активный, т.к. через LED оптрона)
- DIR: LOW = оптрон открыт = сигнал активен
- STEP: импульс LOW для шага  
- ENA: LOW = драйвер включен

## Какую прошивку выбрать?

| Схема подключения | Прошивка |
|-------------------|----------|
| Arduino → Драйвер напрямую | `StepperDriver_DirectWiring` |
| Arduino → Оптрон → Драйвер | `StepperDriver_OptocouplerWiring` |

## Штатный профиль движения (30/40/30)

Обе прошивки по умолчанию используют трапецеидальный профиль движения:
- **minDelay = 200 мкс** (максимальная скорость ≈ 5000 шаг/с)
- **maxDelay = 800 мкс** (начальная/конечная скорость ≈ 1250 шаг/с)
- **Разгон = 30%** от общего количества шагов
- **Крейсер = 40%** на максимальной скорости
- **Торможение = 30%** до полной остановки

## Работа с профилями

### В ПО CrystalTable:
1. **Меню → Сервис → Профили движения** - открывает редактор профилей
2. **Чекбокс "Использовать профили"**:
   - ✅ Включено: профили отправляются в Arduino
   - ⬜ Выключено: Arduino работает со штатными настройками 30/40/30

### Команды протокола:
- `0x07` (SetProfile) - установка профиля с ПК
- `0x08` (GetProfile) - запрос текущего профиля

## Архив

Устаревшие версии прошивок находятся в папке `Archive/`:
- `StepByStep1.5.ino` - оригинальная версия с профилем 30/40/30
- `StepByStepOOP1.3.ino`, `StepByStepOOP1.4/` - промежуточные версии
- `StepByStepInverS/` - версия для инверсной логики

## Быстрый старт

1. Определите схему подключения (прямая или через оптрон)
2. Откройте соответствующую папку
3. Загрузите `.ino` файл в Arduino через Arduino IDE
4. Подключитесь через COM-порт в CrystalTable
5. При необходимости настройте профиль движения
