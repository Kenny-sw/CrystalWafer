# 🎯 БЫСТРЫЙ СТАРТ: НАСТРОЙКА КАМЕРЫ

## ⚡ ЗА 1 МИНУТУ

### 1. ЗАПУСТИТЬ КАМЕРУ
```
Кнопка "📷 Камера" → Выбрать камеру → ОК
```

### 2. ОТКРЫТЬ НАСТРОЙКИ
```
Кнопка "⚙️ Настройки"
```

### 3. ПРОВЕРИТЬ ПОДДЕРЖКУ
```
Кнопка "Проверить поддержку" → Изучить отчет
```

### 4. НАСТРОИТЬ
```
Яркость: 50
Контраст: 50
Насыщенность: 50
Резкость: 5
Усиление: 30
```

### 5. ПРИМЕНИТЬ
```
Кнопка "Применить" → Готово! ✅
```

---

## 🚨 ЕСЛИ НЕ РАБОТАЕТ

### Камера не запускается
```
→ Проверить USB
→ Перезапустить программу
```

### "Проверить поддержку" не активна
```
→ Сначала запустить камеру (📷)
→ Потом открыть настройки
```

### Все показывает ✗
```
→ Обновить драйверы
→ Или купить Logitech C920
```

### Настройки не применяются
```
→ Статус должен быть: 🟢 Камера работает
→ Отключить авто-режимы
```
