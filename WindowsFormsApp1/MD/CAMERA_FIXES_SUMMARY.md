## 🐛 УСТРАНЕНИЕ ПРОБЛЕМ

### Проблема: "Проверить поддержку" не работает

**Причина:** Камера не запущена

**Решение:**
```
1. Закрыть настройки
2. Запустить камеру (📷)
3. Открыть настройки снова
```

---

### Проблема: Все настройки показывают ✗

**Причина:** Камера не поддерживает DirectShow

**Решение:**
```
1. Обновить драйверы
2. Купить Logitech C920
3. Отключить виртуальные камеры
```

---

### Проблема: Настройки не применяются

**Причина:** Автоматические режимы

**Решение:**
```
1. Отключить "Автоэкспозиция"
2. Отключить "Автобаланс белого"
3. Применить снова
```
