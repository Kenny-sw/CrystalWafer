## ✅ ИСПРАВЛЕНО: Критическая проблема Arduino

### Проблема #1: Serial.print во время движения моторов
**Файл:** `Arduino/StepByStep1.5.ino.ino`

**Суть проблемы:**
- `Serial.print()` внутри циклов движения занимает 100-500 мкс
- Нарушает timing импульсов STEP → моторы пропускают шаги
- Движение неравномерное, возможны рывки

**Исправление:**
```cpp
// ❌ БЫЛО: pumpEdgeEvent() внутри циклов
for (uint32_t i=1; i<=accel; ++i) {
    pulseStep();
    delayMicroseconds(...);
    pumpEdgeEvent(); // ← Serial.print нарушает timing!
}

// ✅ СТАЛО: события отправляются ПОСЛЕ движения
void moveProfile(...) {
    // Циклы БЕЗ Serial.print
    for (...) {
        pulseStep();
        delayMicroseconds(...);
        // НЕТ pumpEdgeEvent()
    }
    // События после завершения
    pumpEdgeEvent();
}
```

### Проблема #2: STEP_PULSE_US слишком мал
**Было:** 4 мкс  
**Стало:** 5 мкс  
**Причина:** Некоторые драйверы (особенно оптопарные) требуют ≥5 мкс

## ✅ ДОБАВЛЕНО: Упрощенный протокол для тестирования

### Новый файл: `SimpleSerialController.cs`

**Отличия от стандартного:**
- ❌ НЕТ отдельного listener thread
- ❌ НЕТ TaskCompletionSource
- ❌ НЕТ async/await сложностей
- ✅ Синхронная отправка/прием
- ✅ Простая диагностика
- ✅ Легко отлаживать

**Как использовать:**
1. Зажмите **Shift** и кликните на кнопку **"Connect"**
2. Появится сообщение: "Включен упрощенный протокол"
3. Все команды будут отправляться через SimpleSerialController
4. Для возврата: снова **Shift+Click** на "Connect"

**Когда использовать:**
- Тестирование базовых шагов ЛШД
- Диагностика проблем с портом
- Проверка работы Arduino
- Если стандартный протокол дает сбои

**Логи:**
```
[SIMPLE] Порт COM3 открыт
[SIMPLE] Startup: READY
[SIMPLE] Startup: EV S:1
[SIMPLE] TX -> cmd=0x05, data=0, packet=[05-00-00-00-00-05]
[SIMPLE] RX <- EV L:1
[SIMPLE] RX <- OK
[SIMPLE] Команда выполнена: OK
```

## 🎯 ПОСЛЕДОВАТЕЛЬНОСТЬ ТЕСТИРОВАНИЯ

### Шаг 1: Тест базовых команд (упрощенный протокол)
```
1. Shift+Click на "Connect"
2. Выберите COM-порт → Connect
3. Проверьте логи: "READY", "EV S:1"
4. Нажмите "🔓 Фиксация"
   Ожидается: "EV L:1" + "OK"
5. Нажмите стрелку вверх
   Ожидается: "OK" + движение мотора
6. Нажмите "🔒 Сброс"
   Ожидается: "EV L:0" + "OK"
```

**Если работает:** Arduino и моторы исправны, можно переходить к стандартному протоколу

**Если НЕ работает:** 
- Проверьте Arduino Serial Monitor (115200)
- Проверьте подключение моторов
- Проверьте питание драйверов

### Шаг 2: Тест стандартного протокола
```
1. Shift+Click на "Connect" (выключить Simple)
2. Disconnect → Connect (стандартный)
3. Повторите тесты из Шага 1
```

**Если работает:** Все отлично!

**Если НЕ работает:**
- Проверьте логи listener
- Возможно, проблема в асинхронности
- Используйте Simple для работы
