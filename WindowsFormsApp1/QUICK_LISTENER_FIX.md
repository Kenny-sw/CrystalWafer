# ⚡ БЫСТРОЕ РЕШЕНИЕ: Listener не запущен

## 🔴 Ошибка

**Сообщение:**
```
Listener не запущен или завершился!
Необходимо переподключить COM-порт (Disconnect → Connect)
```

**Причина:** Listener (слушатель ответов от Arduino) остановился из-за ошибки чтения из COM-порта.

---

## ✅ Решение

### Шаг 1: Переподключите COM-порт

1. **Нажмите "Disconnect"** (Отключить)
2. **Подождите 1 секунду**
3. **Нажмите "Connect"** (Подключить)
4. **Проверьте статус:** должно быть "COM подключён: COMx"

### Шаг 2: Проверьте Arduino

Откройте **Arduino IDE → Tools → Serial Monitor (115200 baud)**

**Должно появиться:**
```
READY
EV S:1
```

Если сообщений нет:
- Нажмите кнопку **RESET** на Arduino
- Перезалейте скетч `StepByStep1.5.ino.ino`

### Шаг 3: Проверьте работу

1. Нажмите **"🔓 Фиксация"**
2. В Serial Monitor должно появиться:
   ```
   EV L:1
   OK
   ```
3. Если ответа нет → см. TROUBLESHOOTING_COM_PORT.md

## 📋 Частые причины

### 1. USB-кабель отключен
**Решение:** Проверьте физическое подключение

### 2. Arduino зависла
**Решение:** Нажмите кнопку RESET на Arduino

### 3. Другая программа использует COM-порт
**Решение:** Закройте Arduino IDE Serial Monitor и другие терминалы

### 4. Неправильный COM-порт
**Решение:** 
- Откройте Диспетчер устройств (Win + X)
- Найдите Arduino в разделе "Порты (COM и LPT)"
- Выберите правильный порт в приложении

- `Listener crashed` → критическая ошибка listener
- `Timeout` → Arduino не отвечает
