# 🔧 УСТРАНЕНИЕ ПРОБЛЕМЫ "Failed to send the command"

## 📋 Описание проблемы

При попытке отправки команды на Arduino появляется ошибка:
```
"Failed to send the command. Check COM port status."
```

## 🔍 Диагностика

### 1. Проверка логов приложения

Откройте логи приложения (`Меню → Помощь → Показать логи`) и найдите записи, связанные с отправкой команды. Логи покажут точную причину ошибки:

#### Возможные сообщения в логах:

**А. "Listener не запущен или завершился!"**
```
Listener не запущен или завершился! Попытка перезапуска...
```
**Причина:** Listener (слушатель) ответов от Arduino остановился или не был запущен.

**Решение:**
1. Отключитесь от COM-порта (нажмите "Disconnect")
2. Подключитесь заново (нажмите "Connect")
3. Проверьте, что Arduino отправляет "READY" при подключении

---

**Б. "Serial command 0x{XX} timed out after 3 seconds"**
```
Serial command 0x02 timed out after 3 seconds.
```
**Причина:** Arduino не ответил в течение 3 секунд.

**Решение:**
1. Откройте Arduino IDE → Tools → Serial Monitor (115200 baud)
2. Проверьте, отвечает ли Arduino на команды
3. Убедитесь, что Arduino загружен правильный скетч (`StepByStepOOP1.4.ino`)
4. Проверьте, что Arduino получает питание
5. Перезагрузите Arduino (кнопка RESET)

---

**В. "Failed to write to serial port"**
```
Failed to write to serial port.
```
**Причина:** Ошибка записи в COM-порт (кабель отключен, драйвер упал).

**Решение:**
1. Проверьте физическое подключение USB-кабеля
2. Откройте Диспетчер устройств → Порты (COM и LPT)
3. Убедитесь, что Arduino видна в списке (например, "COM3")
4. Переподключите USB-кабель
5. Перезапустите приложение

---

**Г. "Attempt to send 0x{XX} while port is closed"**
```
Attempt to send 0x02 while COM port is closed.
```
**Причина:** COM-порт не подключен.

**Решение:**
1. Нажмите кнопку "Обнов." чтобы обновить список портов
2. Выберите нужный COM-порт из списка
3. Нажмите "Подкл." (Connect)
4. Дождитесь сообщения "COM подключён: COMx"

---

### 2. Проверка состояния Arduino

#### Шаг 1: Откройте Serial Monitor в Arduino IDE
```
Arduino IDE → Tools → Serial Monitor
Скорость: 115200 baud
```

#### Шаг 2: При подключении должны появиться сообщения:
```
READY
```

#### Шаг 3: Отправьте тестовую команду Lock вручную
В приложении нажмите кнопку "🔓 Фиксация"

В Serial Monitor должны появиться:
```
EV L:1
OK
```

Если ответа нет:
- Arduino не получает команды
- Проверьте скорость передачи (115200 baud)
- Проверьте, что загружен правильный скетч

---

### 3. Проверка формата пакета

Логи показывают отправляемый пакет в формате:
```
TX -> cmd=0x05, data=0, packet=[05-00-00-00-00-05]
```

Формат пакета:
```
[CMD][D0][D1][D2][D3][XOR]
 0x05 0x00 0x00 0x00 0x00 0x05
```

**Контрольная сумма (XOR):**
```
checksum = 0x05 ^ 0x00 ^ 0x00 ^ 0x00 ^ 0x00 = 0x05 ✓
```

Если контрольная сумма не совпадает:
- Arduino вернет: `ERR:CS`
- Проверьте код Arduino и C#

## 🛠️ Пошаговое решение проблемы

### Вариант 1: Быстрая перезагрузка

1. **Отключитесь от COM-порта:**
   - Нажмите кнопку "Disconnect" в приложении

2. **Закройте все программы, использующие COM-порт:**
   - Arduino IDE Serial Monitor
   - Другие терминалы (PuTTY, RealTerm)

3. **Переподключите Arduino:**
   - Отключите USB-кабель
   - Подождите 5 секунд
   - Подключите USB-кабель обратно

4. **Подключитесь в приложении:**
   - Нажмите "Обнов." чтобы обновить список портов
   - Выберите COM-порт
   - Нажмите "Подкл."

5. **Проверьте подключение:**
   - Статус должен показать "COM подключён: COMx"
   - Попробуйте отправить команду

---

### Вариант 2: Полная диагностика

#### 1. Проверка Arduino

```
✓ Arduino подключена к USB
✓ Светодиод питания (ON) горит
✓ Загружен скетч StepByStepOOP1.4.ino
✓ Serial Monitor (115200 baud) показывает "READY"
```

#### 2. Проверка драйверов

Откройте **Диспетчер устройств** (Win + X → Диспетчер устройств):
```
Порты (COM и LPT)
  └─ Arduino Uno (COM3)  ← Должна быть видна
```

Если Arduino НЕ видна:
- Установите драйвер CH340/CP2102/FTDI
- Попробуйте другой USB-кабель
- Попробуйте другой USB-порт

#### 3. Проверка приложения

В приложении:
```
✓ COM-порт выбран из списка
✓ Кнопка "Подкл." показывает "Disconnect"
✓ Статус показывает "COM подключён: COMx"
✓ Режим отладки ВЫКЛЮЧЕН (Наладка → Работа без COM-порта)
```

#### 4. Тест команды Lock

1. Нажмите кнопку "🔓 Фиксация"
2. **Ожидаемый результат:**
   - Статус: "Фиксация: ВКЛ"
   - Кнопка станет красной: "🔒 Сброс"
   - Моторы должны "захватить" позицию

3. **Если ошибка:**
   - Откройте логи (Ctrl+L)
   - Найдите причину ошибки
   - См. раздел "Возможные сообщения в логах"

## ⚠️ Частые ошибки

### 1. Arduino отвечает "ERR:UNLOCKED"

**Причина:** Попытка движения без фиксации.

**Решение:** Нажмите кнопку "🔓 Фиксация" перед движением.

---

### 2. Arduino отвечает "ERR:CS"

**Причина:** Ошибка контрольной суммы пакета.

**Решение:**
- Проверьте, что XOR реализован правильно в коде
- Перезагрузите Arduino
- Перезапустите приложение

---

### 3. Нет ответа от Arduino (Timeout)

**Причина:** Arduino зависла или не получает команды.

**Решение:**
1. Откройте Serial Monitor Arduino IDE
2. Нажмите кнопку RESET на Arduino
3. Должно появиться "READY"
4. Если "READY" не появляется - перезалейте скетч

---

### 4. Listener остановился

**Причина:** Внутренняя ошибка в SerialPortController.

**Решение:**
- Переподключите COM-порт (Disconnect → Connect)
- Перезапустите приложение
- Проверьте логи на наличие исключений
