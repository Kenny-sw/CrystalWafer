# CrystalTable

Приложение Windows Forms для визуализации полупроводниковых пластин (wafer) и управления позиционером через COM-порт.

## 🚀 Быстрый старт

1. Откройте решение `WindowsFormsApp1.sln` в Visual Studio 2019 или новее
2. Восстановите NuGet пакеты (автоматически при сборке)
3. Соберите и запустите проект

## 📋 Требования

- **Платформа**: .NET Framework 4.7.2
- **ОС**: Windows 10 или новее
- **IDE**: Visual Studio 2019+ (рекомендуется 2022)

## 🔧 Основные возможности

- Отображение карты пластины с сеткой кристаллов
- Управление движением позиционера через COM-порт
- Профили движения с настраиваемыми параметрами
- Интеграция с камерой для визуального контроля
- Калибровка системы координат
- Экспорт/импорт данных в различных форматах
- Статистика по кристаллам

## 📁 Структура проекта

```
WindowsFormsApp1/
├── Camera/              # Работа с камерой
├── ComputerVision/      # Компьютерное зрение
├── Controllers/         # Контроллеры (Serial, UI, Mouse, Zoom)
├── Data/               # Модели данных (Crystal, WaferInfo, etc.)
├── Dialogs/            # Диалоговые окна
├── Forms/              # Дополнительные формы
├── Logic/              # Бизнес-логика
├── Properties/         # Настройки приложения
├── Resources/          # Ресурсы
└── Arduino/            # Прошивки для Arduino
```
