# Новый Workflow для CrystalTable

## Обзор изменений

Реализован улучшенный workflow для работы с картами пластин, включающий:
- Управление шаблонами карт
- Работа с партиями пластин
- Система черновиков для безопасного редактирования
- Автоматическая нумерация пластин

## Состояния системы

### 1. Начальное состояние (Initial)

**UI элементы:**
- Выпадающий список с шаблонами
- Кнопка "Создать карту"
- Пустой или последний визуализатор

**Доступные действия:**
- Выбор шаблона из списка
- Создание новой карты

### 2. Редактирование черновика (DraftEditing)

**UI элементы:**
- Панель конструктора с параметрами
- Живая визуализация изменений
- Кнопки "Сохранить" и "Отмена"

**Параметры:**
- Диаметр пластины (мм)
- Размер кристалла (ширина × высота, мм)
- Ширина дорожки (мм)
- Смещение X/Y (мм)
- Отражение по осям X/Y
- Кнопки точной подстройки

**Доступные действия:**
- Изменение параметров с мгновенным обновлением визуализации
- Сохранение карты (переход в MapReady)
- Отмена изменений (возврат в Initial или MapReady)

### 3. Карта готова (MapReady)

**UI элементы:**
- Информация о партии и количестве обработанных пластин
- Кнопка "Редактировать карту"
- Кнопка "Новая пластина"

**Доступные действия:**
- Редактирование существующей карты (переход в MapEditing)
- Начало работы с новой пластиной (переход в WaferProcessing)

### 4. Обработка пластины (WaferProcessing)

**UI элементы:**
- Информация о текущей пластине
- Кнопка "Завершить пластину"
- Кнопка "Архивировать партию"

**Доступные действия:**
- Завершение работы с пластиной (возврат в MapReady)
- Архивирование всей партии (возврат в Initial)

### 5. Редактирование карты (MapEditing)

Аналогично DraftEditing, но для существующей карты.

## Структура данных

### WaferTemplate
Шаблон карты для повторного использования:
```csharp
{
    TemplateName: string
    DiameterMm: float
    CrystalWidthMm: float
    CrystalHeightMm: float
    StreetMm: float
    OffsetXMm: float
    OffsetYMm: float
    MirrorX: bool
    MirrorY: bool
    EdgeExclusionMm: float
    CreatedDate: DateTime
    ModifiedDate: DateTime
}
```

### WaferBatch
Информация о партии пластин:
```csharp
{
    BatchName: string
    Notes: string
    TemplateName: string
    WaferCount: int
    CreatedDate: DateTime
    ModifiedDate: DateTime
    IsArchived: bool
}
```

## Хранение данных

**Шаблоны:**
`%AppData%/CrystalTable/Templates/*.xml`

**Партии:**
`%AppData%/CrystalTable/Batches/*.xml`

## Типичные сценарии использования

### Создание новой карты с нуля

1. Нажать "Создать карту"
2. Ввести название партии и примечание
3. Выбрать "< Создать новый шаблон >"
4. Настроить параметры в конструкторе
5. Нажать "Сохранить карту"

### Создание карты на основе шаблона

1. Выбрать шаблон из выпадающего списка
2. Нажать "Создать карту"
3. Ввести название новой партии
4. Выбрать существующий шаблон
5. При необходимости скорректировать параметры
6. Нажать "Сохранить карту"

### Работа с пластинами

1. После сохранения карты нажать "Новая пластина"
2. Выполнить обработку пластины
3. Нажать "Завершить пластину"
4. Повторить для следующих пластин

### Завершение работы с партией

1. После обработки всех пластин нажать "Архивировать партию"
2. Подтвердить архивацию
3. Система возвращается в начальное состояние
4. Шаблон остается доступным для будущего использования

## Преимущества нового workflow

1. **Минималистичный интерфейс** - только необходимые кнопки в каждый момент
2. **Безопасное редактирование** - все изменения через черновики
3. **Переиспользование настроек** - система шаблонов
4. **Автоматизация** - автоматическая нумерация пластин
5. **Прозрачность** - четкие состояния и переходы
6. **Гибкость** - быстрое создание на основе шаблона или детальная настройка

## Миграция со старого кода

Старые компоненты, которые были удалены:
- `toolStripCreateMapButton`
- `toolStripEditMapButton`
- `toolStripSavePngButton`
- Старая логика MapStartButton/MapApplyButton/MapCancelButton

Новые компоненты:
- `WorkflowController` - управление состояниями
- `WaferTemplate` / `WaferBatch` - модели данных
- `WaferTemplateManager` - управление хранением
- `CreateMapDialog` - диалог создания карты
- Упрощенная панель workflow

## API WorkflowController

```csharp
// Создание новой карты
bool StartNewMap(Form parentForm)

// Управление черновиком
WaferTemplate GetDraftTemplate()
void UpdateDraft(WaferTemplate updatedTemplate)
bool SaveDraft()
void CancelDraft()

// Редактирование карты
bool StartEditMap()

// Работа с пластинами
bool StartNewWafer()
bool FinishWafer()
string GetCurrentWaferName()

// Управление партией
bool ArchiveBatch()
void Reset()

// Доступ к шаблонам
List<WaferTemplate> GetAllTemplates()
WaferTemplate LoadTemplate(string templateName)
```

## События

```csharp
event EventHandler<WorkflowState> StateChanged
```

Срабатывает при изменении состояния workflow, позволяя UI реагировать на изменения.
